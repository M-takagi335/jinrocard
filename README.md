# 人狼デュエル

20種類の役職から20枚のデッキを組み、月夜の決闘でNPCと戦う1対1のカードゲームです。

## 起動

Node.js 22.18以降で実行してください。

```sh
npm ci
npm run dev
```

表示されたURL（通常 http://localhost:5173/）をブラウザで開きます。初期デッキでそのまま「NPC戦を開始」を押せます。編集したデッキはブラウザに保存されます。

- `npm test` — ルールエンジンのテスト。固定乱数による50試合の検証を含みます。
- `npm run build` — 型検査と本番ビルド。静的ホスティング用の出力は `dist/` です。
- `npm run preview` — 本番ビルドをローカルで確認します。

## 構成

- `src/cards.ts`：役職名、分類、効果量、投入上限、最終夜などの基本設定。
- `src/duel.ts`：Reactに依存しない対戦エンジン。選択の確定、公開、解決、中断を伴う対象選択を別の操作に分けています。乱数源とNPCの選択関数を差し替えられます。NPCの選択は夜の選択フェーズに入るときに確定し、相手の手札や選択は渡しません。
- `src/main.tsx` / `src/style.css`：デッキ構築と対戦画面。

オンライン対戦の追加時は、サーバー側に対戦状態と乱数源を置き、両者の確定が揃うまでカードを公開せず、手札・山札・情報カードの結果は権限に応じた表示用データだけを送る構成を想定しています。

### 同時処理の裁定

同時に出た狂人は、互いを対象にした場合も妨害を同時に適用します。複数の狂人が同じカードを無効化することもあります。騎士は相手からの攻撃と反撃の両方に対して、夜全体で軽減量を共有します。猫又は直接攻撃または罠師の反撃でHPダメージを受けると発動し、猫又同士の反撃は連鎖しません。商人のHP消費は回復後、ドローの前に処理します。
