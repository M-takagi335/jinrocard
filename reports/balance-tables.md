## 再実行

Node.js 22.18以降。補充は0、2、3、回復量は3、4。各組み合わせを実行し、同じファイル名へ出力する。

```powershell
foreach ($refill in 0,2,3) {
  foreach ($heal in 3,4) {
    node --disable-warning=ExperimentalWarning --experimental-strip-types scripts/balance.ts $refill $heal 1000 | Set-Content "reports/balance-$refill-$heal.json" -Encoding utf8
    if ($LASTEXITCODE -ne 0) { throw "Simulation failed" }
  }
}
node --disable-warning=ExperimentalWarning --experimental-strip-types scripts/summarize-balance.mjs
npm test
```
