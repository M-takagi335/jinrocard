## 効果処理の再現結果

| カード | 再現した現行動作 |
| --- | --- |
| 狂人 | 1枚出しには不発。2枚出しには個体を無作為に1枚指定。狂人2枚が同じ個体を無効化する場合がある。相互に狂人が無効化されても、先に同時に決めた無効化は両方適用される。 |
| 猫又 | 相手から実HPダメージが入った場合に反撃。全軽減や大狼の自傷では発動せず、罠師の反撃で実HPダメージを受けると発動。猫又同士の反撃は連鎖しない。 |
| 罠師 | 襲撃を無効化し、罠師1枚につき2点を1回反撃。人狼2枚に対して罠師2枚なら、攻撃側に計4点。襲撃枚数で倍増しない。 |
| 騎士 | 1枚につき2点の軽減残量を、通常の攻撃・罠師・猫又の反撃で共有。騎士2枚で4点軽減。 |
| 密偵・道化師 | 相手の公開カードに攻撃カテゴリがあるかを見る。無効化された人狼・猫又も攻撃扱いで、密偵は引き、道化師は引かない。猫又が出ただけで反撃が発生しない場合も同じ。 |
| 魔女＋霊媒師 | 同じ夜に使用中の魔女を回収できない。次の夜に捨て札から同じ個体を手札へ戻し、後の夜に再使用して回復できる。 |

現行カード文言の「攻撃カードを出していれば」は、実ダメージの有無と別の判定。説明を明確にするならカード詳細・ヘルプに「無効化・反撃不発でも、公開された攻撃分類のカードを数える」と追記する案がある。無効化を判定から除く案はカード仕様の変更になる。

## 理論上強そうだが未実証

- 罠師・騎士・猫又を相手の襲撃傾向に合わせ、HP差がついた後だけ守る耐久の特化構成。検証した耐久型は強かったが、このタイミング戦術や個別カードの寄与は隔離していない。
- 狂人を2枚出す相手に絞り、独裁者は別の夜に温存する妨害。妨害型は好成績だが、相手ごとの出し方に適応する方針は今回のAIでは試していない。
- 魔女＋霊媒師を使いながら、墓守・呪術師対策・15夜目を見越して回収順まで最適化する戦術。今回比較したのは手札に魔女がない等の条件での回収優先で、専用の複数夜探索は行っていない。

## 検証用AIの判断と限界

- 両席に同じ検証用選択関数を使用。自分の手札・HP・状態・公開捨て札と、相手のHP・公開される残り役職構成、本人が取得済みの調査情報を入力にする。相手の手札・山札順・今夜の選択は参照しない。ゲームエンジンとは別のシード付き乱数で点数の同点を崩す。
- 各カードの点数を出し、合法な一枚と二枚の全候補を比較。襲撃役の公開比率が高ければ狩人と罠師を、欠損HPが大きければ魔女を、相手HPが低ければ高打点を優先。狩人と罠師の重複、HPの低い大狼・商人、過剰回復を減点。暗殺者は残り枚数・役職の優先度・直近の調査を使う。6型に固有の役職点を設定し、回収優先比較では魔女回収に追加点を与える。
- 捨て札・回収対象の選択は両席で現行エンジンと同じ順位付けを使用。左席の選択プロンプトだけ同じロジックを外部から適用した。回収優先の差は霊媒師・墓守を出す判断であり、回収先を別アルゴリズムに切り替えた比較ではない。
- 各タイプの構成は1例。選択AIは複数夜の探索や相手の学習を行わず、公開の残り枚数を実際の出現確率の近似に使う。調査で見た役職の直近情報は利用するが、預言者の順序や引かれるタイミングを厳密には推論しない。調査型の弱さや、2枚固定との比較を人間に一般化できない。

## 修正・追加検証の順序

1. 空きスロットを検証で拒否する。対戦バランスとは独立に対応できる。
2. 補充2を対人テストの最初の候補にする。魔女4のままで、2枚出し率94.2% → 72.1%、HP0決着率39.7% → 29.7%。相性が改善する一方で長期戦が増えるため、決着のテンポも合わせて評価する。補充0では回収型が68.1%に上がるので、単純に補充をなくす案は優先しない。
3. 魔女を4から3へ下げる案は別に扱う。現行補充3でHP0決着率39.7% → 47.8%、平均終了HP8.61 → 7.12。耐久型は60.2% → 63.1%と上がったため、耐久対策としての一律弱体化は支持されない。
4. 情報型を別構成・別AIでも測る。占い師・預言者の順序や手札情報を戦術に使うAIで再検証し、耐久型の防御枠を一部交換する比較で勝因を切り分ける。
