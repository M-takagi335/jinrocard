# 情報系カード・手札補充の追加検証

前回の [分析報告](balance-analysis.md) と [集計表](balance-tables.md) を踏まえ、魔女4回復を固定して、カードを引く効果と補充枚数を切り分けた。ゲーム既定値はA。追加ドローは検証スクリプトが対戦生成時に明示した場合だけ発動し、通常の対戦画面からは指定しない。

| 設定 | 夜終了時の補充 | 占い師 | 預言者 |
| --- | ---: | --- | --- |
| A | 3枚 | 手札1枚を見る | 山札の上3枚を見る |
| B | 3枚 | 手札1枚を見る＋1枚引く | 山札の上3枚を見る |
| C | 3枚 | 手札1枚を見る＋1枚引く | 山札の上3枚を見る＋1枚引く |
| D | 2枚 | 手札1枚を見る＋1枚引く | 山札の上3枚を見る＋1枚引く |

## 結果と判断

- **構成差が今回の最大の要因。** 同じ基準5デッキに対し、改善AI・Aの情報基準は6.42%、情報＋暗殺者支援は48.76%、情報＋攻撃は18.44%。占い師・預言者・暗殺者はいずれも各2枚を維持している。暗殺者支援では密偵2・道化師2を騎士・魔女・罠師・狂人各1に替えており、改善を暗殺者だけに帰属できない。
- **追加ドロー単独の効果は限定的。** 同じ5相手で情報基準はA→Cで従来AIが5.44%→7.06%、改善AIが6.42%→6.98%。改善AIの暗殺者支援は48.76%→49.94%。補充3枚ではB・Cの効果だけで基準情報型の差は縮まりにくい。
- **調査を予想に使うAIの精度は上がった。** Aで調査由来の記憶がある暗殺者の的中率は57.02%（16,134件）→73.28%（24,204件）。両側のAIが変わり、該当試行の集団も異なるため、改善分の全てを調査ロジックの因果効果とはみなせない。情報基準の同じ5相手での勝率上昇は5.44%→6.42%にとどまる。
- **Dは出し方の偏りを緩和する。** 改善AIのC→Dでは1枚出し4.49%→27.09%、2枚出し95.51%→72.91%。情報基準の勝率は共通5相手で6.98%→19.50%、耐久基準の対情報基準勝率は91.00%→67.00%。ただし最終夜HP判定は61.61%→68.50%に増え、平均決着は13.41→13.72夜に延びる。耐久＋猫又はDの14デッキ集計でも63.23%で、耐久の強い構成が残る。
- **調整候補。** Dは対人テストの候補とし、次は「補充2枚・情報カードは現行のまま」をDと比較する。今回のC→Dは追加ドローを有効にした状態で補充枚数だけを変えており、補充2枚で追加ドローを採用する価値までは測っていない。情報型の構成は、すでにAで五分に近づいた暗殺者支援を先に対人で試せる。

## 方法と信頼性

前回の6基準デッキに8構成を加え、全14デッキの枚数と投入上限を起動時に検証。情報＋暗殺者支援は暗殺者2枚、占い師2枚、預言者2枚を残して攻防を補い、情報＋攻撃は情報カードを残しつつ純粋な打点に寄せた。耐久＋猫又と回収＋魔女保護の主要カードは前回の基準構成で既に上限の2枚なので、周辺カードを入れ替えた構成比較であり、猫又や魔女を1枚増やした場合の比較ではない。全14レシピは [追加検証の集計表](intel-balance-tables.md) に掲載。

同型戦を含む105組に各500シードを使い、左右を入れ替えて計1,000試合ずつ行った。1設定あたり105,000試合、従来AIと改善AIそれぞれ420,000試合、合計840,000試合。各設定の初期シードと座席は共通。追加ドローや異なる判断で途中の乱数消費が変わるため、試合の後半まで引く順序を揃えた比較ではない。集計時に席ごとの試合数と勝利・引分の合計を照合した。1,000試合で50%付近の単純な二項近似では、95%の誤差幅は約±3.1ポイント。シードの再利用と席入れ替えによる相関を織り込んだ信頼区間ではない。小さな差や人間プレイヤーへの一般化は保留する。

両者とも従来AIでA〜Dを先に実行し、次に両者とも改善AIで同じ比較を実施。従来AIは直近1夜の調査結果を役職集合として予想に使う。改善AIは占い師で見た役職と預言者で見た順序を保持し、公開のドロー枚数に応じて予測を進める。公開された使用・捨て札で同名役職の記憶を捨て、山札再構築で順序の予測を破棄する。古い手札情報は夜ごとに重みを下げ、暗殺者の予想に使う際も候補は公開残存役職に限る。直近5夜の相手の襲撃・攻撃率を狩人・罠師などの採点に混ぜ、終盤はHP差で攻守を切り替える。

改善AIが読むのは自分の調査記録、公開された対戦ログと枚数、双方のHP、自分の手札と状態。相手の現在の手札・実際の山札順・今夜の未公開の選択は渡していない。暗殺者の「調査あり」的中率は、予想役職について本人の調査由来の記憶が残る試行に限る。推測に調査が存在したことの指標であり、調査がなければ別の役職を選んだかどうかまでは測っていない。改善AIは有限の履歴と局面評価で判断し、相手の最適反応や複数夜のゲーム木を探索しない。

## 修正した不具合

デッキ検証で添字を1つずつ確認し、空きスロット、undefined、null、不明ID、オブジェクトの継承プロパティ名、枚数と投入上限の違反を拒否する。両席とも対戦構築前に検証し、従来の入力エラーで終了する。前回のクラッシュ再現テストを、拒否動作を確認する回帰テストへ更新した。追加ドローについても、無指定時の現行動作、調査結果の順序、役職別の加算、無効化時の不発をテストした。

```powershell
    node --disable-warning=ExperimentalWarning --experimental-strip-types scripts/intel-balance.ts $variant $mode 500
    if ($LASTEXITCODE -ne 0) { throw "Simulation failed" }
  }
}
node --disable-warning=ExperimentalWarning --experimental-strip-types scripts/summarize-intel-balance.mjs

```
