# 最強NPC導入前の最終比較

対象はWeb版 `jinrocard`。前回の [強いNPC実験](strong-npc-improvement.md) と [暗殺者実験](assassin-npc-improvement.md) を基にした。前回のFは現行「強い」に900試合で535勝・294敗・71分だった。今回、本番ソースと難易度画面には手を加えていない。

## 方式と事前に決めた比較条件

| 方式 | 判断 |
|---|---|
| A | 現行の強いNPC `chooseStrongNpc`。 |
| B（F） | 48シナリオの暗殺者予想、本人の占い師・預言者情報、温存補正、翌夜先読み。 |
| C（G） | 前回の翌夜先読みのみ。調査活用や暗殺者専用補正は使わない。 |
| D | Bと同じ方式で、暗殺者の消費ペナルティと調査を先に使う加点だけ無効化。 |

主試験は各方式30条件、各条件50シード×両席の3,000試合、合計12,000試合。うち現行「強い」とは14同型・4異型、計1,800試合／方式。残る12条件では標準・攻撃・防御回復・1枚出し・2枚出し・合法ランダムを各2条件で対戦させた。

直接対戦はB対C、B対D、D対Cを各1,680試合（6同型と4異型の両デッキ配分、各60シード×両席）、計5,040試合。異型は相手と自分のデッキの担当も反転した。総対戦数17,040。異型・戦術別は固定の対戦表に対する成績で、あらゆるデッキの組み合わせを総当たりした値ではない。試合数を途中で成績に合わせて増減せず、全方式で前回と異なる新しいシードを用いた。

全対戦を正式な `Duel` で解決。20枚・役職上限、HP20、初期5枚、夜末2枚補充、手札最大7枚、15夜制。独裁者、当夜だけ有効な呪術師、商人のHP1消費も現行どおり。標準、バランス、速攻、耐久、情報、コンボ、ランダム、暗殺者1枚・2枚・占い師入り・預言者入り・両方入り、D343、D272を使用した。生成型の固定構成には新規の同一デッキシードを使い、ランダム型だけは対戦ペアごとに生成。詳細構成と対戦表は実行スクリプトに含めた。

標準と強いは本番の関数。攻撃・防御・1枚・2枚出しは既存のルールベースの評価に対応する重みや枚数方針を指定した。ランダムは合法な枚数を等確率に選び、手札から重複なしで抽選する。全方式の追加選択は共通ルールとした。ゲーム乱数とNPC乱数を分離し、同じ局面番号・席に共通の出発シードを使った。経路が分かれたあとは引くカードも変化し得る。

勝率は引き分けを含めた全試合が分母。95%区間は席交換2試合を1ペアとし、対戦条件ごとの分散を集計した正規近似。方式差は同じ対戦条件・シードの勝率差をペアにして計算。多重比較補正は行っていない。戦術別で各戦術に割り当てられたデッキが異なるため、戦術だけの因果効果の推定には使えない。

```powershell
node --experimental-strip-types scripts/strongest-npc-final-review.ts main 50
node --experimental-strip-types scripts/strongest-npc-final-review.ts direct 60
node --experimental-strip-types scripts/strongest-npc-final-review.ts direct-reverse 60
npm test
npm run build
```

## 公平性と先読みの照合

判断には、公開役職枚数・公開捨て札・HP・使用履歴など、自分の手札と本人に許可された調査だけを読み取り専用ビューで渡す。各行動はエンジンの合法判定を通した。非公開手札・山札順・伏せカード・相手限定の調査だけを変えた場合の判断不変性、同夜の調査の先取り禁止、古い調査の減衰、2枚の暗殺者に個別の予想を付ける処理は既存の回帰テストで照合した。生成AI・外部API・通信を使わず、TypeScriptの計算とローカル乱数で判断する。

預言者は公開のドローで「ドロー済み」に移り、山札にある既知位置は手札の仮想プールから除外される。墓守の挿入・再構築・公開使用は既存エンジンの記録を使い、使われた札や位置不明は手札の確証としない。占い師の観測は経過夜と手札の更新で減衰。公開履歴、HP、手札枚数・独裁者の制限も仮想行動に反映する。

HP投影は既存の1,200ケースの正式エンジン照合に加え、魔女＋商人対呪術師＋独裁者、罠師と猫又、狂人と暗殺者・狩人・大狼を含む回帰テストを追加した。山札に余裕がある条件では投影した追加ドロー数・夜開始手札数を照合し、翌夜の独裁者制限を確認。最終夜そのものでは温存を評価せず、実エンジンのHPによる勝敗を確認した。

**先読みを正式エンジンと完全一致させる課題は残る。** 現行F/Gの再現を優先し、仮想ドローは回収や捨て札再構築・7枚超過時の選択を厳密には追わない。第14夜から第15夜を仮想評価するときは、15夜目を直接選ぶときの勝敗評価ではなく、通常のHP評価を使う。今回の勝敗自体はすべて正式エンジンの結果で、この近似の修正は次の評価で独立に扱う。
