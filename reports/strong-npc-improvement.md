# 強いNPCの改善実験

対象はWeb版 `jinrocard` の `75f5caa`。実験用のTypeScriptは `scripts/experimentalStrongNpc.ts` に隔離した。判断はブラウザ内で完結し、生成AI・学習済みモデル・外部API・通信を使用しない。本番の難易度選択、NPC、ゲームルール、デプロイ設定、別リポジトリは実験対象外。

## 現行ロジックと実験構成

現行の「強い」は、公開残存枚数から24の仮想手札を引き、直近最大6夜の公開使用履歴とHPから相手の行動を予測する。自分の合法手を1枚・2枚とも列挙し、終盤HP、致死、手札増加、温存コストを加味する。商人は現行のHP1消費を評価しており、呪術師による当夜の回復阻止もモデルにある。暗殺者には予測した上位2役職を試すが、2枚使用時は同じ役職を各カードに指定する。

主な弱点は、手札2枚の選び方が個別カードの順位の上位を組み合わせる方式であること、温存の価値を固定係数で評価すること、調査結果を利用しないこと。現行は罠師と猫又を含む処理を簡易式で評価する。実験基盤は正式エンジンの段階に沿ってそれぞれを明示的に処理し、下記の照合テストで検証した。

| 方式 | 実験内容 |
|---|---|
| 現行対照 | 両者とも現行の「強い」。 |
| 実験基盤 | 現行に近い評価係数を使い、狂人の無効化・襲撃と特殊ダメージ・罠師・猫又・騎士・回復・自傷をルール順に投影する。予測での乱数消費順と手札供給の近似にも違いがある。 |
| 行動予測 | 実験基盤に公開履歴と残存構成からの襲撃・防御・回復・2枚出しの重みを追加し、相手の仮想手で防御、呪術師、狂人の優先度を調整。 |
| 先読み | 実験基盤の上位4手だけ再評価。今夜の24シナリオのうち4件から残した手札と仮想ドローを作り、翌夜まで比較する。独裁者の枚数制限も翌夜に反映。 |
| 調査活用 | 実験基盤の仮想手札に、本人が得た占い師・預言者の観測を確率的に反映。 |
| 統合 | 行動予測・先読み・調査活用をすべて適用。 |

実験NPCが受け取るのは、順序のない公開デッキ・残存構成、公開HPと枚数・履歴、自分の手札と調査記録などの読み取り専用スナップショット。残存構成は現行UIと同じエンジンの集計を利用し、再利用で捨て札から戻った枚数を反映する。本人の調査だけを付加し、調査した相手カードの個体IDも渡さない。占い師の観測は鮮度と状態で減衰させる。預言者は引かれたことを確認できたカードだけを手札候補として重み付けし、まだ山札にあるカード、使用済み、順番不明は手札の根拠にしない。同じ役職については最も強い根拠だけを使用する。暗殺者は公開残存役職の範囲から予想する。

HP投影と有効カードの一致は、正式エンジンとの1,200ケースの照合テストで確認した。別のテストでは両者が調査した後、相手手札と山札の交換、自他の山札順変更、相手限定の調査・伏せ情報の変更を行い、同じビューと同じ判断を確認した。すべてのシミュレーションで、実際に選んだ手を正式エンジンの合法判定に通した。

## 比較条件

現行のHP20、デッキ20枚、初期手札5枚、毎夜1枚ドロー、夜末に手札が2枚未満なら2枚まで補充、手札上限7枚、15夜制。呪術師は当夜の回復を無効、商人はHP1消費・3枚ドロー。全試合を実際の `Duel` で解決した。共有者などの追加選択は全方式で共通とした。

標準は固定、バランス・速攻・耐久・情報・コンボは固定の生成シードを使用。D343とD272は以前の探索報告の20枚を使用した。ランダム同型はペアごとに両者に同じデッキを生成した。9つの同型戦にD343対D272、情報型対速攻型を加えた。各条件で席を交換し、同じシードを使用した。ゲームとNPCの乱数は別系統とし、各夜・各席で方式間の出発シードをそろえた。行動が分岐すると、その後の抽選と手札も変化し得る。

予備は6ペア／組み合わせで792試合。最終は未使用シードで60ペア／組み合わせ、1方式につき1,320試合、計7,920試合。対照を含む総数は8,712試合。勝率の分母は引き分けを含む全試合。区間は席交換2試合の勝率を1標本とし、組み合わせごとに分散を推定して等重みで集計した正規近似95%区間。対照との差は対応するシード・席ペアの差で計算した。多重比較補正は行っていない。

```powershell
node --experimental-strip-types scripts/strong-npc-improvement.ts pilot 6
node --experimental-strip-types scripts/strong-npc-improvement.ts final 60
npm test
npm run build
```

## 解釈と推奨

- **次の検証候補は先読み単独。** 総合勝率は43.5%で、現行対照の38.3%から5.2ポイント増え、同じ試合で現行側の勝数を30超えた。D343同型で57.5%、耐久同型で43.3%と改善が見られた。一方、コンボ同型で現行対照を下回り、情報型対速攻型では0勝だった。実験基盤との差は+2.8ポイントだが、その区間は0をまたぐ。先読みの効果だけを確定するには独立した再評価が要る。
- **調査活用は的中率に改善の兆候がある。** 実験基盤に加えると全体で29.2%から30.6%、情報型同型で33.8%から36.6%になったが、総合勝率は40.7%から40.2%だった。行動予測だけでも情報型同型で37.0%だった。使用局面や予想した役職が方式間で変わるため、同一公開局面で占い師と預言者を個別に無効化する比較が今後必要。
- **行動予測単独と統合版は、実験基盤に対する改善を確認しきれなかった。** 統合版は情報・コンボ同型で高い成績を出したが、耐久・D343同型では先読み単独の値を下回った。次の評価では、統合に含める各機能を個別に判断する。
- **先読みは翌夜までの近似。** 仮想ドローでの既知山札順や回収・再構築・手札超過の厳密な再現、最終夜の先読みでの勝敗点、3夜先、暗殺者2枚に異なる予想をつける組み合わせは今回の対象外。最終夜そのものの手選びでは勝敗とHP差を評価する。現状は固定計算予算で、時間によるフォールバックは実装していない。採用判断の前に、先読みの処理量を抑えた版と現行を、追加シード・異型戦・実機で比較する。

自動テスト112件、本番ビルド、実験NPCのTypeScript型チェックが通過。本番のソース・設定に変更はなく、実験コードとレポートは専用ブランチに保存する。
