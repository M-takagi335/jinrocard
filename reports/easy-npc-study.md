# やさしいNPCの比較検証

基準はWeb版 `main` の `706ab894fffbd5fc1578b1a5e85d38f4c1ff8f9a`。今回の実装は実験スクリプトだけに含めた。

## 結論

**D方式を「やさしい」の採用候補とする。** 最終評価の全8条件で標準NPCに勝率27.08%（95%区間25.03〜29.14%）、ランダム同士では33.59%（28.37〜38.82%）。標準デッキ同士では22.92%で、目安よりやや低い。勝率に加えて、プレイヤー役の襲撃が通りやすくなり、NPCが削るHPも減るため、今回の目的に最も合う。

| 指標（全8条件） | A 標準 | D |
| --- | ---: | ---: |
| プレイヤー役の襲撃成功率 | 74.88% | 79.31% |
| NPCが防御札を出した夜 | 28.89% | 23.91% |
| NPCが防いだ量／試合 | 5.34 | 4.38 |
| NPCが与えたダメージ／試合 | 16.41 | 13.92 |
| NPCが攻撃札を2枚出した夜 | 9.20% | 4.04% |
| NPCが2枚提出した夜 | 71.65% | 43.24% |
| 平均決着夜 | 12.67 | 12.82 |

ランダム同士でプレイヤー役の襲撃成功率は79.21%から84.54%、NPCの与ダメージは16.84から14.89へ。平均決着夜は10.70から10.98に延びた。手札を温存しやすいC・Dは今回の対照より低勝率だった。一方、Dでは双方が生存して15夜を迎える割合が全条件で46.88%から51.11%へ増えた。終盤に差が埋まるかは相手のデッキにも依存する。

Dでも襲撃札は39.42%の夜、防御札は23.91%の夜に出した。魔女は平均1試合1.96枚、実回復は6.91 HPで、占い師・預言者も使い、予想できる暗殺者はすべて予想を設定した。主比較3,072試合では、Dに満タン時の魔女提出、HP4以下での大狼、コストだけで致死になる商人、回収対象がない状態での回収札提出は観測されなかった。この結果は不自然な手を完全に排除したことを示すものではない。手札が限られる場面や同時公開の読み違いは残る。

**実装を検討する価値はある。** Dは既存の判断を小さく調整でき、EよりNPCからのダメージを減らせた。Eは攻撃を通しやすくする効果が同程度で、2枚を出す夜が多く、標準デッキ同士でDほど弱くしない候補になる。今回のプレイヤー役は標準NPCであり、初心者の勝率や疲れやすさを測定したわけではない。採用判断前に、実際の初心者がランダム同士で数試合遊んだ際の攻撃・防御の分かりやすさを確認する余地がある。

将来の表示案は「やさしい — 初めての方や、気軽に対戦したい方向け。攻撃が通りやすく、相手は1枚で出すことが多めです。」。順番は「やさしい・標準・強い・最強」で、初期選択は標準、ランダムを含むデッキ選択は共通を想定。

| 方式 | 判断方法 |

## 設計と測定

- 正式Duelを使い、集計用のコピーには観測フックだけを追加した。対照Aの判断は本番の関数を直接呼び、B/C/Dはその関数の評価点と確率だけを差し替えた。カード能力・夜の処理・HP判定は本番通りで、密偵は条件成立で2枚。
- 予備1,600試合と最終17,664試合は別シード。最終のうち、Aを相手にした比較は15,360試合、候補同士は2,304試合。標準同士は固定デッキ、ランダム同士は共通生成器で両側を独立生成した。速攻・耐久・情報は、候補側の標準またはランダムと組み合わせてシードごとに生成した。毎回20枚と役職上限を本番の検証関数で確認した。
- ゲーム、デッキ生成、選択の乱数は分離。各シードで左右を交換し、方式間で同じシードとデッキを使った。相手も合法な標準NPCなので、分岐後は手札や選択が変わりうる。追加選択は全方式で同じ既存実験用の優先順位を使用した。
- 勝率の分母は全試合で、引き分けは勝数に含めない。95%区間は左右と同じシードを再利用した組合せをまとめた正規近似。A/Aとの差は同条件の勝利フラグのペア差。表の相手別区間は多重比較補正をしていない。
- 「攻撃札の夜」は攻撃カテゴリのカードを1枚以上提出した夜。「襲撃札の夜」は人狼・大狼・妖狐を1枚以上提出した夜。「防御札の夜」は狩人・罠師・騎士を1枚以上提出した夜。分母はその側が提出判断を行った夜。
- 「相手の襲撃成功率」はプレイヤー役が効果で襲撃値を発生させた夜のうち、防御後に1以上残った割合。混在する騎士の軽減は集計上、襲撃へ先に配分した。特殊攻撃の成否や自傷はこの指標に含めない。「防いだ量」は狩人・罠師の無効化と騎士の実減算の合計。「与ダメ」は襲撃・特殊攻撃・反撃から発生したHP減少で、自傷・商人のコストを除き、同時の自傷でHP0に達した場合は相手のダメージを先に割り当てた。
- 「最終HP差」は候補側−相手側。「HP判定時勝率」は双方が第15夜終了まで生存した試合だけを分母にした勝率。対戦時間はシミュレーターの実行時間で、人間の操作待ちや演出を含む実プレイの所要時間は未測定。

## 検証と再現

提出ごとに本番の合法判定と1枚制限を確認。暗殺者の予想は公開残存候補で照合。終了・山札再利用・手札上限・夜末補充も計測し、進行停止と上限違反は確認されなかった。15対戦条件で観測フック付きの解決と、加工していない正式エンジンの勝敗・最終HP・決着夜が一致した。相手の非公開手札と山札のカードを交換して山札順を逆転させ、許可されたビューと固定乱数での決定が全方式で同じことを確認した。伏せカードや相手専用の調査結果は判断関数へ渡していない。EにはHP2の回復、HP1の商人回避、回復不能時の魔女回避も固定ケースで確認した。
