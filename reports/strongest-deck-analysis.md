# 人狼デュエル：支配的なデッキの自動探索

## 結論

1. **主要な相手すべてに80%以上勝つ構成は、今回の最終評価では見つからなかった。** 361構成を探索し、25構成を未使用シードで評価した。最上位のD343は、基準7型に平均77.6%、最低63.9%（対耐久）。探索で得た相手を加えると、7,920試合で勝率61.8% [60.9%–62.7%]、引分6.4%、最低30.6% [27.0%–34.1%]（対D272、720試合）だった。
2. **最上位への有効な対策を確認した。** D308は混合方針の直接対戦720試合でD343に63.3%勝ち、引分5.6%。D272戦での最上位の勝率が最低だった。対策探索の直接検証で最も高い勝率は、D207→D168の74.0% [70.2%–77.7%]だった。
3. **攻撃特化と耐久特化には相性があった。** 大狼を重視した高火力起点は基準7型に18.1%、旧耐久は60.1%。最上位構成は攻撃・防御回復・ドロー・妨害の混合型。狩人・罠師・魔女を多く積んだ対策は襲撃中心の構成に勝てたが、対策同士の対戦や、基準全体での成績にはばらつきがあった。個々の役職を1枚だけ入れ替えた比較は実施していない。
4. **情報・妨害は組み合わせ次第だった。** 旧情報は基準7型に14.9%、旧妨害は53.3%。上位の耐久寄り対策にも暗殺者や占い師を採用した構成が入り、最上位の攻守混合にも妨害が入った。短期の評価AIで調査に多くの枠を使った旧情報型は苦戦した。カード単体の価値や、人間が情報を活用した場合の勝率は分からない。
5. **相性に加え、AIの判断が成績を左右した。** D343の同じ5相手に対し、相手方針固定で自分が攻撃優先なら77.7%、既存NPCなら55.9%、合法手ランダムなら31.7%。反対に自分を調査活用に固定すると、相手が既存NPCなら73.8%、攻撃優先なら51.9%。既存NPC戦の勝率だけでは、別の方針でも同じ強さを維持できるか判断できない。
6. **ゲームバランスは現行維持を推奨する。** 勝率の偏りは観測したが、有効な対策があり、行動方針を替えると差も変動した。カード性能とルールを切り分けた実験は実施していないため、今回の結果だけで個々の能力や上限の変更を勧める根拠はない。次に検証するなら、同一デッキでの既存NPCの襲撃・防御・2枚出しの判断改善を優先する。

## 調査の方法と信頼性

- 対象はコミット `21af4de` の `src/duel.ts`。本番の `Duel`、`validDeck`、`chooseNpc` を使用し、効果やルールの上書きは行わなかった。20枚と役職別上限（人狼・狩人3、独裁者1、他2）、初期HP20・初期手札5、夜開始1ドロー、1～2枚同時公開（手札なしならパス）、夜終了時は2枚まで補充、上限7枚、山札切れ時は捨て札を再利用。HP0は即決着、両者生存なら第15夜終了のHP比較、同値は引分。通常の標準デッキは画面が両側に使う固定 `STARTER`。
- 効果処理は本番の順序。狂人と次夜妨害を処理し、狩人・罠師は襲撃、騎士はその夜のダメージ合計を軽減。特殊攻撃・反撃・自傷を含む攻撃後にHP0を判定し、生存時に回復、商人のHP消費と追加のHP0判定、調査、ドロー・回収に進む。暗殺者の候補は公開されている残存役職のみで、相手が同名を2枚出しても暗殺者1枚につき判定は1回。占い師は未使用手札1枚、預言者は山札上から最大3枚。両者とも追加ドローなし。
- 過去の [バランス検証](balance-analysis.md) と [情報系の追加検証](intel-balance-analysis.md) を参照。旧6レシピと行動採点の基礎を再利用し、以前の補充3枚や情報追加ドロー付きの検証条件は使わなかった。現行の標準・バランス・速攻・耐久・情報・コンボ・ランダム各1レシピ、旧6レシピ（妨害・情報・回収を含む）、大狼中心・対襲撃・攻撃＋回復の重み付きレシピ、ランダム40件を起点とした。
- 役職別上限内で1〜3枚を交換し、上位を親として42件ずつ3世代探索。基準7型の異なる2方針組で試し、平均×0.65＋最低×0.35で評価。初期スクリーニングは相手・方針組ごとに左右各8試合、上位20は各24試合で再比較した。続けて候補への対策と、対策および基準デッキ双方を見た再改善を3反復した。
- 予算の上限は候補数とセル数から約36.2万試合／実行。**本報告の集計対象は352,512試合**（探索108,432、最終検証244,080）、重複除外後の探索361構成。最終検証の内訳は相手別198,000試合（同型も実行）、対策直接戦2,880試合、方針比較43,200試合。検証用3方針組は自分／相手の順に公開情報／公開情報、調査活用／HP維持、HP維持／攻撃優先。相手ごとの検証は左右各360試合。調査情報の扱いを見直す前の予備実行352,512試合と途中で停止した試行は、この集計には含めない。
- スクリプトの生成シードは `0x6ad38370`。最終評価・対策直接戦・方針比較は探索と重ならないシード番号を使用し、1シードで左右を交換。最終表の行側／列側で異なるAIを割り当てる組があるため、A対BとB対Aは相補的な成績にはならない。候補間の比較では同じ対戦条件に同じシード列を使用。95%区間は引分を勝利に数えず、1シードの左右2試合を1組にしたセル内分散による正規近似。固定した相手と方針での試合乱数の不確実性であり、相手の選び方、25構成から選んだ順位、人間のプレイへの一般化は含まない。
- AIは6種類。既存NPCは本番の採点と予想、攻撃優先は高打点を優遇し、合法なら2枚使用、HP維持は回復・防御と魔女回収、公開情報は残存枚数から襲撃・防御の可能性と終盤HP差を考慮、調査活用はそこに公開使用履歴と自分の占い師・預言者の記録を重み付きで加算する。ランダムは合法な使用枚数・カード・予想役職を抽選する。攻撃優先などにも基礎的な公開情報の評価は共通している。
- 全AIとも相手の非公開手札・山札順・選択中カードを参照しない。調査活用は自分の記録から使用済み・順番不明を除外し、古い記録を減衰。ロールアウトは行わず、複数夜の計画や相手AIへの適応は限定的。捨て札・回収の選択は双方とも本番NPC相当の共通順位。既存NPCのカード選択関数は本番同一で、実験ではエンジンの乱数と選択乱数の系列を分離した。固定された比較相手は各型1レシピで、同じ型の異なる生成結果を網羅せず、全有効構成や人間対戦も未検証。
