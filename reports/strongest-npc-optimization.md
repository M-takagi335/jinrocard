# D方式の先読み・軽量化実験

Web版 `jinrocard`、前回の最終比較 `b6dcd38` を起点にした。以前の [探索](strong-npc-improvement.md)、[暗殺者実験](assassin-npc-improvement.md)、[最終比較](strongest-npc-final-review.md) を参照。比較対象の旧Dは、公開残存札やHP・公開履歴と本人の調査から48シナリオを作り、上位4手・4シナリオで翌夜まで読む。専用の暗殺者温存補正は使わない。

## 実装と照合

- **第14夜の先読み**は、仮想の第15夜を通常のHP得点でなく、HP0・両者生存時のHP比較・同HPの引き分けで採点する。第15夜の直接評価は従来どおり。
- **仮想手札**は、残存構成から仮想手札を取り除いた後、仮想の山札を抽選する。本人が預言者で確認し、位置が現在も有効なカードだけをその位置に置く。仮想カードは種類と個数を保存し、実際の山札の順序・個体IDを受け取らない。
- **仮想の夜終了から翌夜**では、まず有効な商人、共有者、密偵、道化師、霊媒師、墓守を順番に処理する。共有者は2枚引いて1枚捨て、墓守は山札先頭に戻し、山札切れ時だけ捨て札を再利用する。公開札を捨て札に移した後、手札が2枚未満なら補充し、7枚超過分を捨てる。翌夜は通常1枚ドローして再度上限7枚を適用。独裁者は翌夜の上限1枚に作用する。翌夜の暗殺者予想は仮想の残存役職内から選ぶ。
- **残る近似**は、共有者や手札超過の捨て札、回収先などの選択方針、仮想の相手の行動、自分の将来の予想、今夜の調査で新たに分かる情報、翌夜の狂人の乱数モデル。今夜の手の一次評価は従来の供給点を使い、厳密な移動の模擬は上位候補だけに実行する。仮想の将来の勝敗を実際の勝率と見なさない。
- **軽量化**は、48→24シナリオ、先読み4手×4状況→3手×3状況。同じ順序の役職手をまとめるが、異なる役職の使用順と暗殺者ごとの予想は維持。手札に暗殺者がいない場合は予想確率の集計を省く。小さい計算予算や重複除去は判断を変えるため、勝率も比較した。
- **Worker試作**は、固定乱数シードと読み取り専用のNPCビューでEを計算。起動・通信・計算エラーやタイムアウト時は現行「強い」に戻す。ゲーム本体への接続は行っていない。実際の導入時には夜の識別子と確定直前の合法判定、退出時の取り消しが必要。
- **回帰テスト**では既存のHP投影1,200ケースに加え、補充・上限・山札再利用・先頭への回収・共有者の捨て札を正式エンジンと照合した。最終夜の比較、秘密情報を変えた場合の判断不変、Workerの代替処理も確認した。NPCの判断はTypeScriptのルール計算と抽選だけで、AIモデル、外部API、判断時の通信を使用しない。

## 比較条件

各方式792試合×2相手（現行「強い」、旧D）。標準、バランス、速攻、耐久、情報、コンボ、ランダム、暗殺者1枚・2枚・占い師入り・預言者入り・両方入り、D343、D272の14同型と4異型を使用。実際の試合は本番 `Duel` が解決し、毎回合法手を検査。各組み合わせ22シード、両席を評価し、本番と同じデッキ制限を適用した。乱数は過去の比較と別シードで、ゲームとNPCの乱数を分離した。同じ相手に対する各方式で同じ出発シード・固定デッキを使う。ランダム型は同じ席ペアに同じ構成を用いた。異型では実験側の使用デッキを固定した上で席を交換しているため、方式間比較に同条件の対照を使用する。

各相手・方式の比較に使った確定データは計7,920試合。CとEは、仮想の翌夜の予想候補をその時点の残存札に限定する修正前にも試走した。修正前の3,168試合は最終集計から除外し、同じ予定試合数を修正後に再実行した。追加試合の有無やパラメータを勝率に合わせて選んでいない。勝率の分母は引き分けを含む全試合。95%区間は席交換を1ペアとして組み合わせ別の分散を足した正規近似。差分は同じシードと席ペアの差で計算した。

npm run build

## 判断と本番導入までの作業

- **勝率の実測値はC、速度を含めた次の候補はE＋Worker。** Cは現行「強い」に50.6%、旧Dに42.7%で首位。Eは現行に49.7%（394勝・276敗・122分）、旧Dに41.2%（326勝・342敗・124分）。現行相手の同条件でEはAより+6.6ポイント（95%区間 +2.9〜+10.2）。旧Dを使ったBとの対応差は、現行相手で+1.4ポイント（−2.8〜+5.6）、旧D相手で+0.3ポイント（−3.2〜+3.7）。Eの明確な勝率低下は観測されなかったが、この試合数から同等性や旧Dへの優越は確定できない。軽量化だけのDは旧D相手で38.1%。
- **終盤の投影は正式な勝敗を優先。** 第14〜15夜決着の現行戦ではBが49.1%、Cが53.2%、Eが50.4%。旧D戦ではBが43.8%、Cが44.9%、Eが43.6%。終盤まで残った対戦を集計したため、数値だけでは修正の効果を分離できない。
- **Eは調査活用を維持。** 現行相手で暗殺者の的中は590/1,734（34.0%）、旧Dの575/1,665（34.5%）に近い。預言者の裏付けがある予想は57/70、占い師は10/28。使う局面が異なり、占い師の件数も少ないため、役職単独の勝率効果は判断できない。
- **スマートフォン向けに軽量化と別スレッド化を分けて確認。** 負荷ケースのCPU4倍低速化Edgeでは、第14夜のEのp95は31.4ms（旧D 77.3ms）、第15夜は23.0ms（同67.8ms）。Eでも第8夜の最大85.4msがあった。幅320pxのオフライン試験ページでWorkerを動作させ、処理を意図的に長引かせた状態でもカード選択ボタンと音量設定を操作できた。Workerの返答は同期版と一致し、正式エンジンで合法だった。実ゲーム画面への接続、iPhone・Android実機、Worker起動コストの分離測定は未実施。
- **公開は保留。** E＋Workerを実験用の対戦画面に接続し、夜や部屋が変わったときに古い結果を破棄する処理、再試行や中断、実機での操作応答を確認する。勝率の非劣性を採用条件とする場合は、低下を許容する幅を事前に定め、追加シードでEと旧Dを比較する。

自動テスト123件、実験コードとWorkerの型チェック、本番ビルドが通過。従来の標準・強い、オンライン対戦、カード能力、`main`、Vercel・Supabase本番、itch.io版に変更を加えていない。
